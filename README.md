# Kabine Studio

Application de gestion de la marque Kabine Care (Amy et Kayliah) : tableau de bord, publications, feed Instagram, stratégie, partenariats, historique et tâches.

- Site statique (aucune compilation) : `index.html`, `config.js`, icônes et `manifest.webmanifest` pour l'installer sur le téléphone.
- Données, connexion et fichiers : Supabase (`supabase/setup.sql` crée tout, à lancer une fois dans le SQL Editor).
- Mise en ligne : Netlify, relié à ce dépôt GitHub (chaque modification publiée se met en ligne toute seule).

Accès réservé aux adresses listées dans la table `members`.
